# Stats-507 (Datasci 507)

## Description:
Stats 507 - Data Science Programming I at UMich introduces fundamental programming concepts and computational skills for data science. The course covers Python programming, data structures, algorithms, debugging, numerical computation, and problem-solving techniques.

## Purpose of this repository:
This repository contains coursework, programming exercises, assignments, and practice materials from Stats 507. It serves as a personal record of my progress in developing Python programming and computational problem-solving skills throughout the course.
